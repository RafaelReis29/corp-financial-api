Termos de Serviço

Última atualização: 6 de outubro de 2026.

1. Objeto

A Corp Financial API é uma API de demonstração para gestão financeira corporativa B2B (empresas, contatos, contratos, meios de pagamento e faturas), mantida por Rafael Reis para fins de estudo e avaliação de integrações.

2. Uso aceitável

  • Utilize a API para testes, aprendizado e prototipação de integrações.
  • Não envie dados pessoais reais ou informações sensíveis: a base inicial contém registros fictícios inspirados na cultura pop.
  • Não utilize a API para atividades ilícitas ou que sobrecarreguem o serviço.

3. Sem garantias

O serviço é fornecido "como está", sem garantias de disponibilidade, exatidão ou adequação a um fim específico, e sem acordo de nível de serviço (SLA). Os dados podem ser reinicializados a qualquer momento.

4. Dados

Todos os registros iniciais são fictícios e não representam empresas ou pessoas reais. Qualquer semelhança é mera coincidência.

5. Licença

O código e a documentação são distribuídos sob a licença MIT.
